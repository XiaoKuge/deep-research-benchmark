# 03: 名次页、每份报告的复核页和要点池页

**What to build:** 读者打开资料站的名次页，能看到试评六份报告的名次区间横条、三种权重下的净分、有没有严重问题、五个环节的档位和分开的对，并有醒目的'试评演示，不是对产品的评价'。点任一份报告进入它的复核页：每条主要结论的来源标签、对错标签和依据；它写到的要点及层级、重要性；环节评级及引用的原文。另有要点池页列出全部要点和每条有哪几份报告写到。页面由一个生成器从试评数据和第 1.2 版结果文件生成，沿用资料站视觉规则。

- [x] 六个复核页各包含该报告的全部主要结论和写到的要点
