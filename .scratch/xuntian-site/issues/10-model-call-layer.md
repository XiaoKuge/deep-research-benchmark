# 10: 模型调用层

**What to build:** 模拟程序通过一个统一的模块调用本机已登录的三家模型命令行（claude、codex、kimi），另有回放方式供测试。每次调用都写一条完整记录（任务名、厂商、模型、工具限定、提示词全文、回答全文、起止时间、校验值）。工具限定分两档：只给材料（不能上网、不能运行命令、不能写文件）和只读网页。有调用次数上限和只估算不调用的模式。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 三家命令行的非交互调用各有实现，参数依据各工具的帮助信息，并写进说明
- [x] 两档工具限定确实转成了对应的命令行参数（有测试，用假的命令行程序检查收到的参数）
- [x] 回放方式能按任务名和提示词校验值取出录好的回答（有测试）
- [x] 调用记录字段齐全（有测试）
- [x] 调用次数上限和只估算模式（有测试）
- [x] 不读取任何密钥
