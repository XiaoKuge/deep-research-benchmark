# 07: 统一运行程序

**What to build:** 主办方用一条命令按运行计划调用每个智能体：命令行方式（题目原文从标准输入交给申报的命令，标准输出作为报告）或网络接口方式（把题目发到申报的地址，取回报告）。智能体反问时回复规则手册附录二的统一答复一次并记下问题。到时长上限就停止，以届时已交付的内容为准。每次运行保存报告和日志，并按附录四的列写运行记录（含输入校验值是否一致）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 命令行方式和网络接口方式各有测试（假智能体）
- [x] 反问时给出统一答复并记录问题（有测试）
- [x] 超时时停止并记录（有测试）
- [x] 运行记录的列与附录四一致，输入校验值一致性正确记录
- [x] 有使用说明
