# 08: 网页存档程序

**What to build:** 主办方用一条命令把一份报告里引用的网页全部存档：提取网址，逐个取回，保存内容和清单（网址、最终网址、状态码、内容类型、字节数、校验值、取回时间、错误原因）。单个网址失败只记原因，不中断。不调用第三方存档服务。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Markdown 和 HTML 两种报告都能提取网址（有测试）
- [x] 成功、重定向、404、超时四种情况用本地测试服务器测过
- [x] 清单字段齐全
- [x] 有使用说明
