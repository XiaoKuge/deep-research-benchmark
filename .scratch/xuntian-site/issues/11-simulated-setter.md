# 11: 模拟出题者

**What to build:** 主办方用一条命令让大模型按出题手册七步出一道题：评委版题目卡、提问版、裸题版；两次独立调用各写深度地图的核心要点并按数鱼的办法估计是否写全；另一个模型只看交给智能体的两个版本做泄露检查；换一家模型不联网做闭卷对照。输出一个题目目录，格式与出题手册的模板一致，附深度地图校验值和全部调用记录。

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] 一条命令产出完整的题目目录（用回放方式测试）
- [ ] 题目卡三个版本、深度地图要点表的格式与出题手册模板一致
- [ ] 两人对照记录里的估计总数按数鱼公式计算正确（有测试）
- [ ] 泄露检查的提示词里不含深度地图内容（有测试）
- [ ] 闭卷对照使用与写地图不同的厂商，且工具限定为只给材料（有测试）
- [ ] 有使用说明
