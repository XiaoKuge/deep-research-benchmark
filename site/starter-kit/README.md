# 新手包

给参赛队伍的起步材料：申报表模板、示例系统提示词、练习题、交付要求原文、一个示例智能体、一份示例运行计划，以及一个检查报告是否包含五个必备部分的小程序。怎样申报、主办方怎样调用你的智能体，见[参赛队伍技术文档](../teams.html)；统一运行程序的完整说明见[统一运行程序使用说明](../../tools/run_agents.md)。两者与[规则手册](../../notes/rules.html)不一致的，以规则手册为准。

## 里面有什么

| 文件 | 是什么 |
| --- | --- |
| [申报表模板.json](申报表模板.json) | 冻结申报表（规则手册附录三）的模板，统一运行程序能直接读取。现在填的是示例智能体的情况。 |
| [系统提示词.md](系统提示词.md) | 示例系统提示词。申报时要交智能体实际使用的系统提示词全文，这个文件示范它的样子；示例智能体不调用模型，用不到它。 |
| [agent.py](agent.py) | 示例智能体。命令行方式，演示反问约定，不调用任何模型，报告里写明是示例。 |
| [运行计划.json](运行计划.json) | 示例运行计划：用示例智能体跑练习题的提问版和裸题版，各一次。 |
| [练习题/淡水湖/提问版.txt](练习题/淡水湖/提问版.txt) | 练习题的提问版，就是交给智能体的全文。 |
| [练习题/淡水湖/裸题版.txt](练习题/淡水湖/裸题版.txt) | 练习题的裸题版，同上。 |
| [交付要求.txt](交付要求.txt) | 统一交付要求和说明的原文（规则手册附录一）。 |
| [check_report.py](check_report.py) | 检查一份报告是否包含交付要求的五个部分。 |
| [check_report.md](check_report.md) | 检查小程序的说明。 |

练习题的两个文件，前面是[出题手册](../../notes/question-handbook.html#example-lake)第四节实例一的原文，一字不改，其中的“〔运行当日〕”也原样保留；空一行之后是附录一的交付要求和说明，也一字不改。正式比赛时交给智能体的题目文件也是这样：提问版或裸题版的文字，后面接附录一。

## 第一步：原样跑一遍示例

在仓库根目录运行：

```
python3 tools/run_agents.py site/starter-kit/运行计划.json
```

一两秒就跑完。结果在 `site/starter-kit/运行结果/` 下面，按日期、队伍、题目、版本分开：

- `运行记录.csv`：规则手册附录四的运行记录表，每次运行一行。示例智能体反问了一次，“智能体是否提问，问了什么”一列写着它的问题；“输入校验值是否一致”一列是“一致”。
- `示例队/淡水湖/提问版/报告.md`：示例智能体交出的报告。里面写着它收到的题目、反问的问题和收到的统一答复。
- 同一目录下的 `输入.txt`、`标准错误.txt`、`运行日志.json`：实际交给智能体的文字、它写到标准错误的进度、这次运行的完整日志。

再检查两份报告是否包含五个必备部分：

```
python3 site/starter-kit/check_report.py site/starter-kit/运行结果/*/示例队/淡水湖/*/报告.md
```

两份都是“结论：合格”，另有一条提醒：示例没有查任何来源，报告里没有网址。

同一天再跑一遍，已经有结果的运行会被跳过；想从头再跑，先删掉 `site/starter-kit/运行结果/` 目录。

## 第二步：换成你的智能体

1. 把 `申报表模板.json` 复制一份，按你的智能体填写每一项。每一项都必须填，不能空着；各项写什么，见[技术文档的“申报智能体”一节](../teams.html#declare)。
2. 把你的系统提示词全文存成一个文件，路径写进“系统提示词文件”。
3. 改“调用方式”。命令行方式写启动命令，网络接口方式写地址。两种方式的约定见[技术文档的“主办方怎样调用你的智能体”一节](../teams.html#call)。
4. 在 `运行计划.json` 的“智能体”里换成你的申报文件的路径（相对于运行计划所在的目录）。
5. 跑一遍，看运行记录和报告，再用检查小程序检查报告。

示例运行计划的时长上限写的是 120 分钟〔默认〕，以主办方确认为准，与正式运行相同。只想试一下调用通不通，可以临时改小，例如 5。

## 几点注意

- **不要改练习题文件。** 运行计划里写了两个文件的校验值，文件改过一个字节，运行记录就会写“不一致”。这正是正式运行时核对输入的办法。
- **所有题目用同一套配置。** 示例智能体反问的是一句对所有题目都一样的话；你的智能体也不能针对某一道题或某一个版本单独配置（规则手册第二节）。
- **只在 macOS 和 Linux 上运行。** 命令行方式的反问用到命名管道，Windows 不支持。
- **示例不是调研。** 示例智能体不调用模型，不检索，报告只照录它收到的内容。它只用来看清调用方式和反问约定。
